# PhishGuard — Phishing Awareness Training

A modern, interactive, browser-based phishing awareness training module created for the CodeAlpha Cyber Security Internship.

## Features

- Professional dark cybersecurity dashboard
- Explanation of phishing, spear phishing, smishing, and vishing
- Fictional suspicious email examples
- Fake website recognition guidance
- Social engineering tactics
- Practical safety checklist
- Interactive 8-question quiz with score feedback
- Responsive layout for desktop and mobile
- No backend and no collection of personal information

## How to run

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html`, or open it in a browser.
3. Navigate through the modules using the sidebar.
4. Complete the quiz.

## GitHub repository name

`CodeAlpha_PhishingAwareness`

## Suggested demonstration

1. Open the dashboard.
2. Explain the purpose of the training.
3. Show the suspicious email examples and identify their red flags.
4. Demonstrate the fake website safety guidance.
5. Open the safety checklist.
6. Complete the interactive quiz.
7. Show the final score.

## Safety note

All examples are fictional and intended for defensive education. This project does not collect credentials, send messages, or interact with real phishing infrastructure.
